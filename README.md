# AxyvornOS

**AxyvornOS** est un système d'exploitation basé sur **Arch Linux**, avec **KDE Plasma**, pensé pour proposer une expérience Linux orientée gaming.

> 🚧 **Projet en développement :** Axyvorn évolue encore. Le matériel et les jeux n'ont pas tous été testés. Des problèmes peuvent donc survenir selon la configuration.

## Fonctionnalités

- Base Arch Linux.
- Bureau KDE Plasma.
- Steam et Lutris préinstallés.
- Installateur graphique Axyvorn.
- Outil graphique de mise à jour.

## Télécharger Axyvorn

➡️ **[Télécharger la dernière version](https://github.com/BloxPulse/axyvorn-releases/releases/latest)**

Les versions précédentes sont disponibles dans la [liste des Releases](https://github.com/BloxPulse/axyvorn-releases/releases).

### Important : reconstruire l'ISO

L'ISO est publiée en plusieurs morceaux afin de respecter la limite de taille des fichiers GitHub.

1. Ouvre la dernière Release.
2. Télécharge tous les fichiers `.iso.part-*` ainsi que `SHA256SUMS`.
3. Recolle les morceaux pour reconstruire le fichier ISO. Les commandes pour Windows, Linux et macOS sont indiquées dans la Release.
4. Vérifie l'ISO assemblée avec la somme SHA-256 fournie.

## Avant l'installation

- Axyvorn est encore en développement : utilise-le comme système expérimental.
- Commence de préférence par un test dans une machine virtuelle ou sur un disque de test.
- Sauvegarde tes fichiers importants avant toute installation.
- Vérifie soigneusement le disque sélectionné : l'installation peut modifier ou effacer les données qui s'y trouvent.
- La compatibilité des jeux, des cartes graphiques et des périphériques reste à tester.
